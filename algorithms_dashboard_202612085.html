Growth Ladder — inclusion hierarchy

Rosen §3.2
O(1)constant
O(log n)logarithmic
O(n)linear
O(n log n)linearithmic
O(n²)quadratic
O(2ⁿ)exponential — intractable

Each class contains all the classes above it: O(1) ⊂ O(log n) ⊂ O(n) ⊂ O(n log n) ⊂ O(n²) ⊂ O(2ⁿ). A problem is tractable if it admits a polynomial-time algorithm.
